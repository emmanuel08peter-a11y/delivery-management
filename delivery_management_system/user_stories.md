# User Stories

## 1. Introduction

User stories describe the features of the Local Delivery
Order & Dispatch Management System from the perspective
of people who will use the application.

## 2. Customer Management

### User Story 1: Register a Customer
As a delivery manager, I want to register customers
so that their information can be stored for future orders.

### User Story 2: View Customer Information
As a delivery manager, I want to view customer details
so that I can access their contact information and address.

### User Story 3: Search for a Customer
As a delivery manager, I want to search for a customer
so that I can find their information quickly.

## 3. Order Management

### User Story 4: Create an Order
As a delivery manager, I want to create a delivery order
so that a customer's package can be recorded in the system.

### User Story 5: View Orders
As a delivery manager, I want to view all delivery orders
so that I can monitor the business's delivery activities.

### User Story 6: Search for an Order
As a delivery manager, I want to search for an order
so that I can find its details quickly.

### User Story 7: Cancel an Order
As a delivery manager, I want to cancel an order
when necessary so that cancelled deliveries are recorded.

## 4. Delivery Rider Management

### User Story 8: Register a Rider
As a delivery manager, I want to register delivery riders
so that their information is available in the system.

### User Story 9: Assign a Rider
As a delivery manager, I want to assign a rider to an order
so that the delivery can be carried out.

## 5. Delivery Status Management

### User Story 10: Update Delivery Status
As a delivery manager, I want to update an order's status
so that I can track its progress.

### User Story 11: Confirm Delivery
As a delivery manager, I want to mark an order as delivered
so that completed deliveries are recorded.

## 6. Reports and Export

### User Story 12: View Dashboard Statistics
As a delivery manager, I want to view order statistics
so that I can understand the business's performance.

### User Story 13: Export Orders
As a delivery manager, I want to export order records
to a CSV file so that I can use them for reporting.

## 7. Acceptance Criteria

The system will be considered successful when:

- Customers can be registered and searched.
- Delivery orders can be created and viewed.
- Riders can be registered and assigned to orders.
- Order statuses can be updated.
- Orders can be cancelled when appropriate.
- Dashboard statistics display correct information.
- Order records can be exported to CSV.
- Information remains saved after the application closes.
